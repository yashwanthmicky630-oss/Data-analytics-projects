# Project 3: Sales Dashboard - Power BI

## Dashboard Preview
- Created interactive sales dashboard with slicers for Region, Category
- KPIs: Total Sales, Total Profit, Profit Margin
- Charts: Bar chart (Profit by Region), Pie (Sales by Category), Line (Monthly Trend)

## Key Insights
1. West region: 35% of total profit
2. Technology: Highest profit margin (25%)
3. Q4 has highest sales - seasonal peak

## Tools
Power BI Desktop, DAX, Power Query
